# 常见问题（FAQ）

## 1. 为什么管理员后台测试 TMDB 时提示超时，但影库依然能刮削出海报？
* 国内网络环境直连 `api.themoviedb.org` 通常受阻。月映内置了 **「TMDB 主源 + 豆瓣直连兜底」** 双重机制：当 TMDB 未填 Key 或超时时，会自动切换至国内可直连的豆瓣接口刮削海报与简介，因此无需代理也能正常使用。
* 如需优先使用 TMDB，可在后台「TMDB 与刮削设置」填入可用的代理地址或镜像域名后保存再测。

## 2. 收藏与追更会修改我夸克网盘里的原文件名吗？
* **不会**。为了避免明文版权名触发夸克分享/文件和谐风控，月映会原样保留原分享的混淆文件夹名与视频文件名，正式片名与海报仅保存在本地数据库做映射展示。

## 3. 游客预览次数有限制吗？
* 管理员可在「管理 → 游客防风控与注册权限」自定义每小时/每天试看次数、最高画质限制（默认不限制 4K），以及是否开放自助注册（默认关闭，仅管理员可建号或开启）。

## 4. 临时预览会不会把夸克网盘撑爆？
* 不会。临时缓存默认最长保留 **12 小时**、总容量上限 **500 GB**，超时或超容后后台会自动按从旧到新顺序异步彻底清理（含清空回收站记录）；同时可在后台自定义上限或随时一键清空。

## 5. Docker 部署后如何在后台配置宿主机代理（如 `127.0.0.1:7890`）？
* 使用官方 `docker-compose.yml` 时，后台「TMDB 代理地址」和「搜索代理地址」直接填写宿主机上的 **`http://127.0.0.1:7890`** 即可（程序在容器内会自动将其映射到宿主机网关），保存前可点击卡片右上角 **「测试代理连通性」** / **「测试连通性」** 验证。
