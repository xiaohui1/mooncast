## 核心特性

* **9 级本地搜片排序、低并发验活与渐进加载**：
  * 双层降噪（多链接汇总帖局部上下文隔离、防和谐标题归一化、非影视与 `<30MB` 空包拦截），8 线程分页验活 + 单条 403 违规隔离 + 连续 2 次 429 温和冷却，首屏 20 条秒出并静默补齐至 60 条；
  * 零额外请求识破标题党虚标集数、多季合集严格优先单季、短剧/衍生片自动降权、剥离网盘 SVIP 伪 60 帧广告语、按单集均体积/整片体积客观加权与同字节克隆沉底。
* **4K 蓝光 302 直连 & PC / 移动端双视图影院播放器**：
  * 302 原画直连零 NAS 代理流量；桌面端提供 macOS 悬浮毛玻璃影院与快捷键，移动端（竖屏/横屏）采用独立双视图布局（极简单行底栏、全屏右侧选集抽屉、彻底防滚动误触）；
  * 内置 6 阶段外挂字幕编码自动探测（原生兼容 UTF-16 LE/BE、GB18030/GBK）、ASS 矢量绘图坐标滤除与 5 级中文字幕智能持久关联。
* **「一起看」共享观影房间**：
  * 支持最多 5 人跨网同步观影、房主控制权开关、30 秒周期 NTP RTT 半程偏移校准、三段式无感漂移追赶（`<0.8s` 死区 / `0.8s~3.0s` 施加 `±3%` 平滑倍速 / `>=3.0s` 硬跳）、弱网缓冲保护与单向显式指令零回环。
* **全链路 0ms 异步清理 & 追更「原子整体换源」**：
  * 预览关闭 0ms 立刻止声关窗，所有夸克临时目录与回收站清理全部后台异步执行；
  * 目录树与追更统一执行四档八级画质优选（`4K 60帧高码 > 4K 60帧 > 4K 高码 > 4K HDR > 4K > 1080P > 杜比视界沉底`），原分享失效时支持一键「原子整体换源」（新仓转存成功后再切换数据库并后台异步清理旧云盘目录，绝不丢片）。
* **TMDB + 豆瓣双源刮削、账号安全加固 & 后台一键系统更新**：国内直连豆瓣自动兜底与 30 分钟双层缓存、防伪造真实 IP 分档限流、注册验证码及管理员多节点一键测速升级。

## 核心本地算法一览（100% 确定性算法 · 零外部 AI 依赖）

月映的核心体验不依赖昂贵且不稳定的云端 AI，而是由四大 **100% 本地确定性工程算法** 驱动——毫秒级响应、完全可复现、全链路单元测试回归把关：

| 算法引擎 | 解决的核心痛点 | 关键技术机制 |
| :--- | :--- | :--- |
| **一、搜片降噪与 9 级排序** | 死链泛滥、汇总帖串片、标题虚标集数、短剧与伪 60 帧广告抢榜 | L1/L2 双层净化 · 8 线程分页验活 · `403` 隔离与连续 2 次 `429` 冷却 · `include_items` 虚标识破 · 双版体积折半与同字节克隆沉底 |
| **二、目录画质与原子换源** | 杜比视界在普通屏幕绿紫偏色、追更断链后重找源易错集/留垃圾 | 杜比音轨隔离 · `400→10` 四档八级评分 · 单集均体积破平 · 纯杜比兜底 · 新仓转存 + 后台异步删旧仓 |
| **三、一起看放映室同步** | 多端跨网进度漂移、频繁 seek 卡顿与多端相互触发 ping-pong 震荡 | 30s NTP RTT 半程偏移校准 · 期望播放点推算 · 三段式漂移校准（`±3%` 无感变速）· `readyState < 3` 缓冲保护 · 操作者回显忽略 |
| **四、外挂字幕全链路解码** | 原盘 UTF-16/GBK 字幕加载失败、ASS 矢量特效坐标刷屏、切集丢字幕 | 6 阶段 BOM / 奇偶位 `0x00` 启发式编码探测 · ASS `[Events]` 作用域与 `{\p1}` 绘图过滤 · 5 级关联与简英双语优先打分 |

> 👉 **查看完整数学公式、流程图与状态机详解：[阅读《核心算法与工程架构白皮书》](docs/ALGORITHMS.md)**

## 快速部署

### 方式一：Docker 一键部署（推荐，单目录 `/data` 持久化）

```yaml
services:
  mooncast:
    image: ghcr.io/xiaohui1/mooncast:latest
    container_name: mooncast
    restart: unless-stopped
    ports:
      - "5220:5220"
    extra_hosts:
      - "host.docker.internal:host-gateway"
    environment:
      - TZ=Asia/Shanghai
      - MOONCAST_DATA=/data
    volumes:
      - ./data:/data
```

或直接前往 [Releases](https://github.com/xiaohui1/mooncast/releases) 下载 `mooncast-vX.Y.Z-docker-kit.zip` 解压后执行：

```bash
docker compose up -d
```

### 方式二：飞牛 fnOS 原生安装包（`.fpk`）

1. 前往 [Releases](https://github.com/xiaohui1/mooncast/releases) 下载对应架构安装包：
   * x86_64 机型：`mooncast_X.Y.Z_x86.fpk`
   * ARM64 机型：`mooncast_X.Y.Z_arm.fpk`
2. 打开飞牛应用中心 → **手动安装** → 上传 `.fpk` 完成安装（默认端口 `5220`）。

## 首次使用说明

1. 启动后访问 `http://<你的设备IP>:5220`。
2. 首次启动会在挂载目录 `/data/init_credentials.txt` 生成初始管理员账号与随机密码（日志中也会输出）。
3. 登录后进入顶部 **「管理」** 页面：
   * 扫码登录更新 **夸克 Web Cookie** 与 **QuarkTV 4K 凭证**；
   * 其余路径、游客限流、临时缓存与刮削源均有开箱即用的默认配置，可按需微调。
